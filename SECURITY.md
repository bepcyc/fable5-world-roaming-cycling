# Security policy

LAAS is a personal experimental project — there is no support SLA and no
release line beyond the latest `main`. If you believe you have found a
security issue (e.g. in the Electron shell, the BLE stack, or the Strava
upload path), please do not file a public issue with exploit details;
instead email the owner (see the GitHub profile of `bepcyc`, the sole
committer) or open a GitHub issue describing it at a high level without
reproduction details, and we will follow up. Reports are handled on a
best-effort basis.
